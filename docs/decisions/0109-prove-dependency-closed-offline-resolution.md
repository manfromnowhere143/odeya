# ADR 0109: Prove dependency-closed offline resolution and cross-object replay

- Status: Proposed architecture candidate; not operator accepted
- Date: 2026-08-01
- Decision owners: canonical identity, schema contracts, registries, replay,
  security
- Gate effect: retains one bounded two-implementation offline-resolution and
  binding-replay observation over a declared repository universe; does not
  resolve historical ledger identities, compute a product identity, issue or
  admit anything, close PRQ-002, accept Gate A, or authorize runtime work

## Context

The architecture status has carried "complete transitive consumer migration,
versioned offline retention, and closed `$ref` replay" as open Gate A
blockers since the candidate corpus was assembled. ADRs 0106–0108 proved
raw-aware traces, serialization conformance, and nine-domain governance —
but every one of those tranches resolved references only within the exact
twelve-schema `odeya-jcs-0.3` cohort, and no retained evidence yet shows
that the *whole* current candidate graph is dependency-closed: that every
schema `$ref` across the full corpus and every declared digest binding in
the retained candidate records and suite artifacts resolves from repository
bytes alone, with no network, file-search, environment, alias, bare-ID,
`latest`, or fallback path.

The current session handoff names this as the sole next machine unit before
the accountable-review and operator-acceptance prerequisites.

## Decision

### Declare one exact resolution universe

Retain a deterministic, answer-free universe manifest generated by
`tests/profile-0-3-offline-resolution/authoring/generate_universe.py` from
explicit rules only — never from directory discovery at verification time.
The universe comprises: every retained schema under `schemas/`; the
`odeya-jcs-0.2` and `odeya-jcs-0.3` candidate core, evidence, and migration
records and the raw-number token contract under `architecture/`; the nine
frozen structural-nonidentity fixtures; and the retained manifests, source
manifests, results, and receipts of the PRQ-002F, PRQ-002G, and PRQ-002H
suites. The manifest binds each member's role and repository path; member
counts are decimal strings. Four historical resource identities with no
current local resource — `command-contract-registry:0.1.0`,
`command-receipt:0.3.0`, `work-contract:0.1.0`, and the retained exact
`command-envelope:0.4.0` vocabulary source — remain outside this universe by
design and are named residue, not silently resolved or fabricated.

### Resolve every schema reference offline

Two source- and language-separated zero-dependency implementations (CPython
3.14.2; Node.js 24.18.0) each build the schema registry solely from
universe members that parse as JSON Schema resources with a
`urn:odeya:schema:` identifier, then walk every schema node and classify
every `$ref`: an in-document fragment must resolve by exact RFC 6901
pointer; an absolute `urn:odeya:schema:` reference must resolve to a
registry member, recording the target's `$id`, repository path, and raw
SHA-256, with any fragment then resolved inside the target; and any other
form — an HTTP or file URL, a relative path, a bare or aliased identifier,
an unknown URN, an unresolvable fragment, or a `$dynamicRef` — refuses.
The complete ordered edge list is retained, and reference resolution
consults nothing but the loaded universe bytes.

### Replay every declared digest binding

Each implementation additionally walks every JSON universe member for the
three declared binding shapes retained by this repository's evidence chain —
`{repository_path, raw_sha256[, byte_count_decimal]}`,
`{path, raw_digest, byte_count}`, and
`{schema_path, schema_raw_digest, schema_byte_count}` — and, for every
occurrence, recomputes the referenced repository file's raw SHA-256 and byte
count from bytes and requires exact equality. A binding whose target is
missing, symlinked, outside the repository, or whose digest or byte count
differs refuses. Binding shapes outside the three declared forms are not
claimed and remain future work, named rather than implied.

Each implementation emits one deterministic projection with the complete
reference-edge and binding-edge censuses and per-edge rows; agreement is
exact-byte projection equality, bound by an external comparison receipt
written last. Execution receipts remain self-attested byte-consistency
records.

### Validate with a parent gate and known-bads

The dedicated validator
`scripts/validate_profile_0_3_offline_resolution.py` regenerates the
universe manifest deterministically, byte-binds it and both retained
projections, cross-checks the retained censuses, executes an embedded
known-bad corpus in which every mutation refuses with its declared singleton
code — including an out-of-universe reference, a digest-binding break, a
universe-member drop, and symmetric coherent forgeries of both results —
and supports `--recompute-all` re-execution of both runners.

## Required evidence before any broader claim

Known-bads must make at least these boundaries load-bearing: universe census
tampering, member drop or duplication, an injected out-of-universe or
malformed `$ref`, a broken digest-binding edge, retained-projection
tampering including coherent symmetric forgeries, result cross-copying,
receipt and comparison binding drift, integral-float census smuggling, and
any flip of a false closure, identity, or authority nonclaim.

Passing establishes only that the declared universe is dependency-closed
under the declared reference and binding forms at the retaining commit.

## Non-decisions

This decision does not:

- resolve, migrate, or fabricate the four named historical resource
  identities, or claim closed replay for any byte outside the declared
  universe and shapes;
- compute a product identity or digest, issue or admit any profile or
  resource, or migrate any consumer;
- establish organizational independence, independent-host reproduction,
  causal historical execution, accountable review, or operator acceptance;
- close PRQ-002 or any other prerequisite, accept Gate A, or authorize
  implementation; or
- authorize runtime, deployment, credentials, spending, data access,
  scientific or product publication, or any external effect beyond the
  separately governed architecture-repository publication of the retaining
  commit itself.

## Consequences

"Complete offline resolution" stops being an aspiration row and becomes a
measured, refusal-guarded property of the declared universe: every schema
reference and every declared digest edge in the current candidate graph is
now proven to resolve from repository bytes alone, twice, byte-identically.
What remains before a Gate A candidate is the work no session can
self-supply: an accountable non-author review of the open findings and the
operator's exact-byte profile decision.
